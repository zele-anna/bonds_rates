# SQLite-хранилище MOEX-облигаций + макро, расчёт VaR
## Цель проекта
Реализовать на Python небольшой ETL-пайплайн, который загружает данные по облигациям с Московской биржи (MOEX), торговые данные по датам и макроэкономические временные ряды (официальный API Банка России), сохраняет всё в SQLite и рассчитывает риск-метрику VaR историческим методом.
### Установка, настройка и запуск
Все необходимые зависимости указаны в файле [pyproject.toml](pyproject.toml)

### Использование функций и примеры работы
#### Реализованы функции загрузки данных по облигациям с Московской биржи [moex_parser.py](src/moex_parser_1.py):
1. get_bonds_by_matdate - Функция для получения списка облигаций со сроком погашения в заданном диапазоне.
- Параметры функции: start_date, end_date (str, формат дат ГГГГ-ММ-ДД).
- Параметры запроса: "iss.meta":\
"off" - отключение мета-данных из ответа,\
"iss.only": "securities" - ограничивает ответ только данными об облигациях
- Возвращает таблицу DataFrame с основными показателями облигаций.
2. get_trading_data - Функция для получения данных о торгах по конкретной облигации.
- Параметры функции: bond (str) - ISIN облигации, period_start, period_end (str, формат дат ГГГГ-ММ-ДД) - даты периода, за который необходимо получить информацию.
- Параметры запроса: \
"iss.meta": "off" - отключение мета-данных из ответа,\
"sort_order": "acs" - порядок сортировки по возрастанию,\
"from": - переданный параметр начала периода (формат ГГГГ-ММ-ДД) - задается пользователем,\
"till": - переданный параметр окончания периода (формат ГГГГ-ММ-ДД),\
"limit": 100 - количество выводимых на странице строк,\
"start": 0 - страница,\
"numtrades": 1 - минимальное количество сделок,\
"tradingsession": "3" - данные Итого по всем сессиям,\
"history.columns": - фильтрация данных ответа по указанным столбцам. 
- Возвращает таблицу DataFrame с торговыми данными по облигации за указанный период.

#### Реализованы функции загрузки данных ЦБ [cbr_parser.py](src/cbr_parser.py):
1. get_key_rate - Загрузка данных по ключевой ставке через веб-форму ЦБ.
- Параметры функции: date_from, date_to (str, формат дат ДД.ММ.ГГГГ).
- Возвращает таблицу DataFrame с данными по ключевой ставке за указанный период.
2. get_cbr_zcyc_params - Загрузка данных КБД (G-кривой) с сайта ЦБ РФ.
- Параметры функции: date_from, date_to (str, формат дат ДД.ММ.ГГГГ).
- Возвращает таблицу DataFrame с данными по кривой доходности за указанный период.

#### Реализованы функции работы с базой данных [db_manager.py](src/db_manager.py):
1. save_data_to_db - Функция сохранения данных в базу данных.
- Параметры функции: data - данные в формате DataFrame, db_name (str) - наименование базы, table_name (str) - наименование таблицы.
- Сохраняет данные DataFrame в указанную таблицу указанной базы.

#### Точка входа
[main.py](src/main.py)\
Запуск скрипта: python src/main.py.\
В скрипте задаются входные параметры периодов для загрузки данных и вызываются функции
загрузки данных с Московской биржи и ЦБ РФ. Полученные данные сохраняются в базу данных в 3 таблицы:
- "bonds" - основные параметры облигаций;
- "trading_data" - торговые данные по облигациям;
- "macro_data" - макроэкономические показатели.
